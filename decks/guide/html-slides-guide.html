한 번 등록하기

원본 HTML 을 한 번 등록합니다 — 원본은 저장소 폴더 밖 어디에 있어도 됩니다.

> slides add "발표.html" --name my-talk --folder conf --title "발표 제목"
  1. 복사저장소의 decks/conf/my-talk.html 로 옮겨 둡니다
  2. 커밋·올리기그 덱 파일만 골라 커밋하고 GitHub 에 올립니다
  3. 갤러리1~2분 뒤 첫 장 그림이 붙은 카드가 생깁니다

발표일·학회·PPTX 도 함께: --date 2026-10-29 --venue "학회 이름" --pptx 발표.pptx

2

고치면 바로 반영

켜 두면 원본을 저장할 때마다 저장소에 올라갑니다(저장마다 공개 기록이 하나씩 쌓입니다).

> slides watch
  1. 저장등록한 원본 HTML 을 평소처럼 고치고 저장합니다
  2. 8초 기다림저장이 이어지는 동안은 기다렸다가 한 번에 올립니다
  3. 바뀐 덱만바뀐 덱 파일만 커밋하고 GitHub 에 올립니다
  4. 갤러리1~2분 뒤 새 판이 보입니다

한 번만 맞추려면 slides sync, 상태는 slides list

저장소 쪽 사본이 웹 업로드 등으로 바뀌었으면 덮지 않고 알려 줍니다.

3

웹에서 올리기

명령 없이 브라우저만으로도 올릴 수 있습니다(저장소 주인만).

  1. ‘올리기’갤러리 오른쪽 위 단추를 누르면 GitHub 업로드 화면이 열립니다
  2. 끌어 놓기HTML 파일을 끌어 놓고 Commit changes 를 누릅니다
  3. 갤러리1~2분 뒤 카드가 생깁니다

고친 판은 카드의 ⋯ → 새 판 올리기에서 같은 파일 이름으로 올리면 바뀝니다.

그림·스크립트가 따로 있는 덱은 폴더째 올리고, 첫 화면 파일 이름을 index.html 로 둡니다.

알아 둘 것

  • 공개 저장소올린 덱은 누구나 볼 수 있습니다 — 갤러리 목록과 저장소에 다 보입니다.
  • 지워지지 않는 기록내린 덱과 이전 판도 기록에 남습니다. 민감한 내용은 올리지 마세요.
  • 검색 제외 요청noindex 표시를 붙이지만 보장되지는 않습니다(저장소 화면 등은 검색될 수 있음).
  • 내리기slides remove my-talk — 갤러리에서 빠집니다.
