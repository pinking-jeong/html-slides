발표자료 올리는 법

1이 PC 에서 올리기 — 권장

저장소 폴더에서 원본 HTML 을 한 번 등록하면 저장소에 올라가고, 1~2분 뒤 이 화면에 나타납니다. 원본은 저장소 폴더 밖 어디에 두어도 됩니다(PowerShell 에서는 .\slides).

slides add "발표.html" --name my-talk --folder conf --title "발표 제목"

발표일·학회·PPTX 도 함께 붙일 수 있습니다: --date 2026-10-29 --venue "학회 이름" --pptx "발표.pptx"

+PDF·PPTX 도 올릴 수 있습니다

같은 명령에 PDF 나 PPTX 를 주면 됩니다. PDF 는 이 갤러리 안에서 바로 재생되고(외부 서비스 없음), PPTX 는 Microsoft Office 웹 뷰어로 재생됩니다 — 파일 주소가 Microsoft 로 전달되고, 10 MB 가 넘으면 받기만 됩니다.

slides add "발표.pdf" --title "발표 제목"
slides add "발표.pptx" --title "발표 제목"

10 MB 가 넘는 PPTX 는 PowerPoint 에서 PDF 로 내보내 함께 올리세요 — PDF 로 재생하고 PPTX 는 받기로 붙습니다: slides add "발표.pdf" --pptx "발표.pptx"

2고치면 바로 반영

아래 명령을 켜 두면, 등록한 원본 HTML 을 저장할 때마다 저장소에 자동으로 올라갑니다. 저장할 때마다 공개 기록(커밋)이 하나씩 쌓입니다.

slides watch

한 번만 맞추려면 slides sync, 상태는 slides list 로 봅니다. 웹에서 올린 판은 덮지 않고 알려 줍니다.

+첫 화면에서 분류·순서 바꾸기

위의 편집을 누르면 카드를 끌어 순서를 바꾸고(카드의 화살표 단추로도 됨), 카드마다 분류를 고를 수 있습니다. 분류 관리에서 분류를 만들고 이름과 차례를 바꿉니다. 덱 파일은 옮기지 않으므로 덱 주소는 그대로입니다.

저장은 저장소 주인만 됩니다 — 이 저장소에만 쓰기 권한이 있는 GitHub 토큰을 넣거나, 토큰 없이 GitHub 편집 화면에 붙여 넣어 저장합니다. 저장한 배치는 decks/gallery.json 에 남고 1~2분 뒤 모두에게 보입니다.

3웹에서 올리기

위의 ‘올리기’를 누르면 GitHub 업로드 화면이 열립니다(저장소 주인만 바로 올라갑니다). 파일을 끌어 놓고 Commit changes 를 누르면 됩니다. 고친 판은 카드의 ⋯ → 새 판 올리기에서 같은 파일 이름으로 올리면 바뀝니다. 저장소 폴더를 통째로 끌어 놓지는 마세요.

알아 둘 것

  • 공개 저장소라 올린 덱은 누구나 볼 수 있습니다(갤러리 목록과 저장소에 다 보임).
  • 올린 것은 지워지지 않는다고 보세요 — 내린 덱과 이전 판도 기록에 남습니다. 민감한 내용은 올리지 마세요.
  • PPTX 를 올리면 만든 이·발표자 노트도, PDF 를 올리면 만든 이·제목 같은 문서 정보도 함께 공개됩니다.
  • GitHub 화면에서 올리거나 저장하면 GitHub 계정의 기본 메일이 커밋에 남습니다 — GitHub 설정 → Emails 의 Keep my email addresses private 를 켜 두면 noreply 주소로 남습니다.
  • 검색 제외(noindex)는 요청일 뿐 보장되지 않고, PDF·PPTX 파일에는 붙일 수도 없습니다.
  • 다른 사람이 보낸 제안(pull request)의 덱은 합치지 마세요.
  • 내리기: slides remove my-talk

분류 관리

이름을 고치고 ↑ ↓ 로 차례를 바꿉니다. 덱이 있는 분류와 덱 파일이 든 폴더는 지울 수 없습니다. 바꾼 것은 ‘저장’해야 모두에게 보입니다.

    배치 저장

    1토큰으로 바로 저장 — 권장

    이 저장소에만 쓰기 권한이 있는 GitHub 토큰(fine-grained)을 넣으면 바로 저장됩니다. 토큰은 이 페이지가 열려 있는 동안만 기억하고, 이 페이지는 어디에도 적어 두지 않습니다(새로 고치면 다시 넣어야 함). 브라우저가 비밀번호로 저장할지 물으면 저장하지 마세요.

    토큰을 기억해 두었습니다 ·

    토큰 만들기 — 열린 화면의 Repository access 에서 Only select repositories 를 골라 이 저장소만 넣으세요. 이름·기한(90일)·권한(Contents 읽기·쓰기)은 미리 채워집니다. 다른 권한은 주지 마세요.

    2토큰 없이 GitHub 화면에서 저장

    배치 내용을 복사하고 GitHub 편집 화면을 엽니다. 내용을 모두 지우고(Ctrl+A) 붙여 넣은 뒤(Ctrl+V) Commit changes 를 누르세요. 이 방법은 GitHub 계정의 기본 메일이 커밋에 남습니다(‘올리는 법’의 알아 둘 것 참고).

    GitHub 화면이 열리지 않았으면 여기를 누르세요
